# Profile: huấn luyện mô hình (ảnh, bảng/văn bản, tín hiệu y sinh)
Dùng khi: điểm chấm dựa vào chất lượng mô hình bạn tự train/fine-tune.
- Đội: agent chính, `ml-engineer` theo skill `ml-experiment-loop`, `mle-reviewer` trước khi chốt, `pytorch-build-resolver` khi lỗi môi trường; thêm `fullstack-dev` + `devops-deployer` nếu cần demo.
- Bắt buộc: split đóng băng có kiểm tra rò rỉ, baseline tự động, mỗi thí nghiệm đổi một thứ, `results.md`, chọn trên val và mở test cho ứng viên cuối.
- Thời gian: GPU trên Colab/Kaggle; chạy thử pipeline bằng dữ liệu nhỏ trước khi train thật.
